Tipografía

Botones

Inputs de texto

Campos amplios con foco claro mediante un anillo de color de acento. Estados de error y ayuda incluidos.

Number input

Sin flechas, con separador de miles y decimales en formato local: 1.000.000,00. El valor numérico real queda disponible para tu lógica.

Con stepper custom (sin flechas nativas)

Select custom

Dropdown propio con navegación por teclado (flechas, Enter, Esc), búsqueda visual del seleccionado y cierre al hacer click afuera.

Date picker

Calendario propio, semana de lunes a domingo, con navegación de meses, día de hoy y acceso rápido. Devuelve dd/mm/aaaa.

Time picker

Selector de hora en formato 24h con columnas de horas y minutos desplazables. Devuelve HH:MM.
